# Mahdiyar Gharaei — Portfolio Website

A bilingual (Persian/English), responsive portfolio website.

## Files
- `index.html`: page structure and SEO metadata
- `styles.css`: responsive design system
- `script.js`: language switcher and mobile navigation
- `assets/`: profile photo, certificate and project artwork
- `robots.txt`, `sitemap.xml`: basic search-engine discovery files

## Publish
Upload the contents of this folder to GitHub Pages, Netlify, or a hosting provider with HTTPS. For a custom domain:
1. Replace `YOUR-DOMAIN.example` in `robots.txt` and `sitemap.xml`.
2. Add your domain to Google Search Console and submit the sitemap.
3. Add your professional email and any missing project details.
